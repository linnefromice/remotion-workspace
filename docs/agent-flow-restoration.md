## [1]→[2] 引き渡し票

### 1. 芯

> **AIが「借主負担」と言った請求を、そのまま入居者に出してよいのか。**

退去精算は、金額を決めるのが貸主側で、払うのが借主という非対称な場面。
だからこそ**業者でも人でもない第3の主体（ガイドライン）が先に効く**ことを見せる。

### 2. 主体と権限

| 主体 | 決められること | 決められないこと |
|---|---|---|
| 立会担当 | 現地の事実（どこが、どう毀損しているか） | 負担区分の最終決定 |
| **AI** | 損耗の分類の下書き、見積との突合 | **区分の確定。借主負担を増やすこと** |
| **ガイドライン** | **通常損耗を貸主負担に確定する。経過年数で負担割合を下げる** | 借主負担を増やすこと |
| 入居台帳 | 入居年数（＝残存価値割合の入力） | 区分 |
| 担当者 | 借主負担を**減らす**のは自由。**増やすには根拠が要る** | ガイドラインの区分を覆すこと |
| 精算記録 | — | （追記のみ） |

**AIの出力を覆せる主体**: ガイドライン。AIが「借主負担・全面張替」と言っても、
通常損耗に分類されれば貸主負担になり、経過年数を超えていれば負担割合が落ちる。

### 3. 工程（7つ）

| # | 工程 | 何が増えるか |
|---|---|---|
| 1 | 退去立会い | 写真・チェックシート・入居年数が揃う |
| 2 | 損耗の分類（AI） | 箇所ごとに「通常損耗／善管注意義務違反／故意過失」の**生出力** |
| 3 | **ガイドラインで区分を確定** | 通常損耗は貸主負担へ。AIの分類は残る |
| 4 | **経過年数で負担割合を計算** | 残存価値割合（クロスは6年で1円） |
| 5 | 見積との突合 | 施工範囲が過大でないかの判定（㎡単位が原則） |
| 6 | 担当者の確認 | 増額するなら理由。減額は自由 |
| 7 | 精算書の発行 | 借主に渡る1枚と、根拠の記録 |

### 4. 記録されるもの

- AIの分類の生出力（確定値と別に残す）
- 適用したガイドラインの条項と、計算に使った経過年数
- 担当者が増額した場合の理由
- 精算書の発行履歴（追記のみ）

### 5. 通らない経路

- **特約による借主負担**: 要件（明確な合意など）を満たさないと無効。今回の筋では通らない
- **経過年数を超えていても負担が生じる場合**: 故意・過失による毀損の補修では、
  資材の残存価値が1円でも**作業費相当は借主負担になりうる**。今回の筋では通らないが、
  経路としては残す
- **全面張替**: 毀損箇所を含む一面までは可。それを超える範囲は通らない

### 6. 1件の具体シナリオ

- 入居6年2か月、単身、退去
- 立会いの所見（自由文）: 「リビング壁に、家具の設置跡とは別に、
  幅20cmほどの引っかき傷が1箇所。台所側の壁は変色あり」
- **AIの生出力**: `{"部位":"壁クロス","分類":"故意過失","範囲":"部屋全面"}`
- **ガイドラインの結論**: 変色は通常損耗 → **貸主負担**。
  引っかき傷は借主負担だが、**入居6年で残存価値1円**。範囲は**一面まで**
- **確定**: 借主負担は実質ゼロ〜作業費相当
- 所要: 立会いから精算書まで **3営業日**（※シナリオ値）

## [2] 図の設計

### ClaimIntake との関係（ここが面白い）

ClaimIntake では、ルールは**昇格しかできない**（緊急度を上げる方向のみ）。
この図では、ルールは**減額しかできない**（借主負担を下げる方向のみ）。

**同じ骨格の鏡像**になる。2枚を並べると
「決定論のルールは、常に一方向にしか効かない」という主張が立体になる。

| | ClaimIntake | Restoration |
|---|---|---|
| ルールの向き | 上げる（安全側） | 下げる（借主側） |
| 人ができること | 下げる（理由必須） | 上げる（理由必須） |
| ルールの形 | 数値の閾値 | **定義（通常損耗）＋数値表（残存価値割合）** |

### 骨格

```
┌─ 外側 ─┬──────── ランタイム枠 ────────┐  ┌ 記録層 ┐
│ ▢ 退去者 │ ROW_1 立会 → 分類(AI) → GL確定 │  │ ▭ 立会記録│
│ ▢ 施工業者│ ROW_2 経過年数 → 見積突合      │  │ ▭ AI分類 │
└─────────┴──────────────────────────────┘  │ ▭ 確定値 │
              ▢ 担当者     ▢ 精算書           └────────┘
```

### 色

パターン集 §4 のとおり主体に割り当てる。**ガイドラインは白。**

| 主体 | 色 |
|---|---|
| 立会い・入力 | シアン |
| AIの分類 | 紫 |
| **ガイドライン** | **白** |
| 担当者 | オレンジ |
| 記録・精算書 | 緑 |
| 通らない経路 | 灰・破線 |

### 山場のパネル

ClaimIntake の「判定の非対称」に相当するもの。**3つの値を並べる。**

```
AI（生出力）      部屋全面 / 故意過失      judgments に残る
ガイドライン      一面まで / 残存価値1円   経過年数6年
確定              実質ゼロ                 増額するなら人の理由
```

上書きのアニメーションは作らない。**AIの値を消さずに並べる**のは ClaimIntake と同じ。

## 決定と、残っている前提

- **立会いの入力**（決定）: 担当者の自由文が必須、写真とチェックシートは任意。
  図では自由文を実線、添付を破線にして「無くても先へ進む」ことを見せている
- **施工業者の置き場**（実装時に修正）: 当初 ランタイム枠の中に「施工業者」を置いていたが、
  業者は枠の外の主体。枠の中には「見積の受領」を置き、外から受け取る形に直した

残っているもの。

1. **経過年数の起算**。前回の張替時点か、入居開始時点か。運用が分かれるはず
3. **担当者が増額する場面が実際にあるか。** 無いなら、人の工程は
   「確認して発行する」だけになり、権限の非対称が薄くなる
4. **3営業日というシナリオ値が妥当か。** 実務の感覚とずれていると、そこで信用を失う
