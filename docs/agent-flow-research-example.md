# 実例：「洗い出し」を一度回してみた

[`agent-flow-research-prompts.md`](./agent-flow-research-prompts.md) の依頼書1（洗い出し）を、
実際に Web検索つきで1回実行した記録。2026-09-17。

**対象**: 日本の不動産賃貸管理会社（従業員50〜300名）

この業界は既に ClaimIntake で図にしているので、**対照実験を兼ねている**。
依頼文が効いていれば、既に作った題材が上位に出てくるはず。

> ⚠️ 以下は1回の調査の出力で、粗探し（依頼書3）を通していない。
> **候補の一覧として使えるが、そのまま図にしない。**

---

## 出てきた10件

充足した条件の番号は依頼書の 1〜6。

|---|---|---|---|
| 1 | **退去時の原状回復の負担区分判定** | 1,2,3,4,5,6 | 国交省 原状回復ガイドライン（残存価値割合の表つき） |

| 3 | **改修・解体前の石綿事前調査の要否判定** | 1,2,3,4,5,6 | 大気汚染防止法・石綿則の事前調査報告制度 |

### 上位3件の中身

**1. 原状回復の負担区分判定**

- 非対称: 過大請求は消費者相談・少額訴訟・行政指導に発展し、ガイドラインと
  異なる請求は敗訴しやすい。少なく見積もった損失は自社の修繕費負担にとどまる
- 入口と出口: 立会いの写真・チェックシート・入居年数 → 箇所ごとの負担区分と割合
- 主体: 立会担当（事実認定）／AI（損耗分類の下書き）／**ガイドライン**（通常損耗は
  貸主負担と決める。AIは覆せない）／入居台帳（入居年数＝残存価値割合）／精算記録
- 出典: [本文PDF](https://www.mlit.go.jp/jutakukentiku/house/torikumi/honbun2.pdf) /
  [令和5年3月 参考資料](https://www.mlit.go.jp/jutakukentiku/house/content/001611293.pdf)

**3. 石綿事前調査の要否判定**

- 非対称: 調査と報告を欠いたまま着工すると法令違反。飛散があれば健康被害と
  回復不能な責任。空振りは調査費用のみ。**非対称の度合いが10件で最も大きい**
- 主体: 元請（実施義務者）／AI（対象工事かの下書き）／**法令の閾値**（床面積・
  請負金額で機械的に決まる）／物件台帳（築年・建材）／報告記録
- 出典: [環境省](https://www.env.go.jp/air/asbestos/post_87.html) /
  [厚労省 報告システム](https://www.ishiwata-houkoku.mhlw.go.jp/shinsei/faq)
- **【要確認】** 制度開始年が検索結果で2022年4月と2023年4月に割れた。
  閾値（解体80㎡・改修100万円）も二次情報のみ

**4. 法定点検の期限管理**

- 主体: 点検業者（事実の記録）／AI（所見の分類）／**法定周期**（日付が機械的に
  決まる。AIは動かせない）／建物台帳／報告記録
- 出典: [東京消防庁](https://www.tfd.metro.tokyo.lg.jp/lfe/office_adv/tenken_houkoku.html) /
  [国交省 定期報告制度](https://www.mlit.go.jp/jutakukentiku/build/jutakukentiku_house_tk_000039.html)
- **【要確認】** 共同住宅が定期報告の対象になるかは規模と特定行政庁の指定による。一律ではない

## わかったこと

### 対照は成立した

**ClaimIntake が2位で出てきた。** 同じ業界を指定して、実際に作った題材が
上位に再現されたので、条件の並びは的外れではなかった。

### 効いた条件：4（文書のルールがあるか）

**順位がほぼ「明文の規程があるか」で決まった。** 1・3・4・5・8・9位は、
すべてルールが法令の条文としてそのまま存在する。

[`agent-flow-discovery.md`](./agent-flow-discovery.md) §2.2 で
「規程は決定論ルールの金脈」と書いたことの裏付けになっている。
逆に2位（ClaimIntake）は明文のルールが無いぶん条件4を落としていて、
**実装では自分たちでルールを5本作る必要があった**のと符合する。

### 効かなかった条件：5（待ち時間）

10件中ほぼ全部が満たしてしまい、順位の判別にまったく寄与しなかった。
→ **「その長さを具体的に言える」ことを要求する形に直した。**

### 依頼文の穴：主体の水増し

「主体が3つ以上」と書いただけでは、**台帳や記録を並べるだけで満たせてしまう。**
実際、6・7・10位は台帳を主体に数えているが、台帳は何も決めていない。

→ 条件3を「**そのうち少なくとも1つはAIの出力を覆せる**」に直した。
物差しは「AIがこう言っても、これが優先される」と言えるかどうか。

### 実際に誤りが1件混ざっていた

入居申込の反社チェックの根拠として、**犯罪収益移転防止法を挙げようとした。**
しかし同法の宅建業者の特定取引は**売買とその代理・媒介に限られ、
賃貸の媒介は対象外**だった（[国交省](https://www.mlit.go.jp/totikensangyo/const/1_6_bf_000025.html) /
[全日本不動産協会](https://www.zennichi.or.jp/law_faq/%E7%8A%AF%E7%BD%AA%E3%81%AB%E3%82%88%E3%82%8B%E5%8F%8E%E7%9B%8A%E3%81%AE%E7%A7%BB%E8%BB%A2%E9%98%B2%E6%AD%A2%E3%81%AB%E9%96%A2%E3%81%99%E3%82%8B-%E6%B3%95%E5%BE%8B%E4%B8%8A%E3%81%AE%E5%8F%96%E5%BC%95/)）。

賃貸管理会社の根拠は暴排条例と自社・保証会社の基準になる。

**そのまま書いていたら、誤った根拠のまま図になっていた。**
依頼書3（粗探し）を別セッションに通す価値がここに出ている。

## 次にやるなら

1. この10件に**粗探し（依頼書3）を通す**。特に6・7・10の主体の水増しと、
   3の【要確認】2件が落ちるはず
2. 残ったものから1件選んで**深掘り（依頼書2）**に進む。
   **1位（原状回復）が最有力**。ガイドラインが残存価値割合の表まで持っていて、
   決定論のルールをそのまま図の第3の主体にできる
3. 条件3と5を直した依頼書で、**別の業界でもう一度回す**。
   同じ穴が出ないかを確かめる
