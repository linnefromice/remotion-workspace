# 業界別の当てどころ

[`agent-flow-research-prompts.md`](./agent-flow-research-prompts.md) の依頼書1（洗い出し）で、
`<対象>` に何を書くかと、その業界のどこを掘ると当たるかの一覧。

> **ここに挙げた法令・ガイドラインの名前は「探す先の当たり」であって、
> 裏取り済みの事実ではない。** 名前が正確か、いま有効か、その業務に本当に適用されるかは、
> 依頼書1・2の中でLLMに出典を出させ、依頼書3（粗探し）で潰すこと。
>
> 実際、不動産で回したときに「犯罪収益移転防止法は賃貸の媒介には適用されない」という
> 誤りが1件混ざった（[実例](./agent-flow-research-example.md)）。

---

## 掘る場所は3つしかない

業界が変わっても、探す物は同じ。

| 探す物 | なぜ |
|---|---|
| **明文のルール** | これがあるかで順位がほぼ決まる。**AIでも人でもない第3の主体**を立てられる |
| **見逃しの事故** | 「間違いのコストが非対称」を直接探す方法。行政処分・事故報告・判例 |
| **非構造の入口** | 自由文・音声・写真で来るもの。ここがエージェントの仕事になる |

**明文のルールが数値や列挙で書かれている業界ほど当たる。**
「◯時間以内」「◯㎡以上」「次の各号に掲げる」は、そのまま決定論のルールになる。

## 業界別

各ブロックの1行目が、依頼書1の `<対象>` に貼る文。

### 運輸・トラック運送

```
日本の一般貨物自動車運送事業者（車両30〜100台規模）
```

| | |
|---|---|
| ルールの当たり | 自動車運転者の労働時間等の改善基準告示（拘束時間・休息期間が**数値で固定**）、点呼と記録の義務、アルコール検知器の使用義務、運行管理者の選任 |
| 非対称 | 過労運転・飲酒の見逃しは事業停止や車両停止の処分と人身事故。空振りは配車の組み直しのみ |
| 非構造の入口 | 点呼記録の所見、日報の自由文、デジタコの逸脱ログ |
| 覆せる主体の候補 | 改善基準告示の上限（AIが「大丈夫」と言っても超えれば不可） |

**数値ルールが明文で存在する点で、この一覧では最も当たりやすい。**

### 介護（訪問介護・通所介護）

```
日本の介護サービス事業者（訪問介護・通所介護、拠点3〜20）
```

| | |
|---|---|
| ルールの当たり | 介護保険法の指定基準・運営基準、自治体の事故報告様式と報告対象の定義、身体拘束・虐待防止の義務、BCPの策定義務 |
| 非対称 | 事故・虐待の兆候の見逃しは指定取消と人身。空振りは確認の手間 |
| 非構造の入口 | 訪問記録・申し送りの自由文、ヒヤリハット報告 |
| 覆せる主体の候補 | 自治体が定める「報告すべき事故」の定義 |

### 建設・施工管理

```
日本の総合建設会社または専門工事会社（施工管理、年商10〜100億）
```

| | |
|---|---|
| ルールの当たり | 労働安全衛生法と各規則（墜落・重機・作業主任者）、石綿障害予防規則、建設業法の施工体制台帳 |
| 非対称 | 危険の見逃しは死亡災害と送検。空振りは作業の一時中断のみ |
| 非構造の入口 | 日報・KY記録・現場写真 |
| 覆せる主体の候補 | 安衛法の禁止事項（「作業を止める」権限が法にある） |

### 学校・教育

```
日本の私立学校法人（中学・高校、生徒500〜2000名）
```

| | |
|---|---|
| ルールの当たり | いじめ防止対策推進法（**「重大事態」が法で定義されている**）、学校保健安全法、各校のいじめ防止基本方針 |
| 非対称 | 重大事態の認定漏れは、取り返しがつかない。空振りは調査の手間 |
| 非構造の入口 | アンケートの自由記述、相談記録、保護者からの連絡 |
| 覆せる主体の候補 | 法が定める重大事態の定義（該当すれば学校の裁量で下げられない） |

**「見逃しのコストが極端に非対称」という点では一覧で最も強い。**

### 食品製造・外食

```
日本の食品製造業者（HACCP対応済み、従業員50〜300名）
```

| | |
|---|---|
| ルールの当たり | 食品衛生法とHACCPに沿った衛生管理、食品表示法のアレルゲン表示義務、自主回収の届出制度 |
| 非対称 | アレルゲンの表示漏れは人身。空振りは表示の刷り直し |
| 非構造の入口 | 仕入先の原材料規格書（PDF・書式ばらばら）、クレームの自由文 |
| 覆せる主体の候補 | 表示基準の義務表示項目（列挙されている） |

### 小売・EC（製品事故・回収）

```
日本の小売事業者またはEC事業者（自社商品を扱う、年商50〜500億）
```

| | |
|---|---|
| ルールの当たり | 消費生活用製品安全法の**重大製品事故の報告義務（期限が日数で決まる）**、景品表示法、リコールのガイドライン |
| 非対称 | 重大事故の報告漏れは公表と処分。空振りは調査コスト |
| 非構造の入口 | レビュー・問い合わせ・SNSの自由文 |
| 覆せる主体の候補 | 消安法の重大製品事故の定義と報告期限 |

### 保険代理店・地域金融

```
日本の乗合保険代理店（募集人20〜100名）
```

| | |
|---|---|
| ルールの当たり | 保険業法の意向把握義務・情報提供義務、金融庁の監督指針、適合性の原則、犯罪収益移転防止法（**こちらは金融機関では対象**） |
| 非対称 | 不適合な販売は業務改善命令。空振りは追加ヒアリングの手間 |
| 非構造の入口 | 面談記録・意向確認書の自由記入欄・通話録音 |
| 覆せる主体の候補 | 適合性の判定基準（年齢・資産・商品の組み合わせで機械的に決まる部分） |

### 人材紹介・派遣

```
日本の人材派遣会社（登録者1000名以上、拠点5〜30）
```

| | |
|---|---|
| ルールの当たり | 労働者派遣法（**派遣禁止業務が列挙されている**、抵触日の管理）、職業安定法の明示事項、労働基準法 |
| 非対称 | 禁止業務への派遣や抵触日の徒過は事業停止。空振りは求人票の書き直し |
| 非構造の入口 | 求人票の業務内容、クライアントからの依頼メール |
| 覆せる主体の候補 | 派遣禁止業務の列挙、抵触日（日付で決まる） |

### 労務・社会保険（社労士事務所または事業会社の人事）

```
日本の社会保険労務士事務所（顧問先100〜500社）
```

| | |
|---|---|
| ルールの当たり | 労働基準法の時間外上限、36協定の限度、安衛法のストレスチェックと産業医面接、育児介護休業法の期限 |
| 非対称 | 上限超過の見逃しは是正勧告と未払い賃金。空振りは確認の手間 |
| 非構造の入口 | 顧問先からの相談メール、勤怠の備考欄 |
| 覆せる主体の候補 | 時間外の上限（数値で固定） |

### 自治体・公共の申請窓口

```
日本の基礎自治体（人口5〜30万、給付金・補助金の申請審査窓口）
```

| | |
|---|---|
| ルールの当たり | 各制度の要綱・交付要領（**支給要件が号立てで列挙されている**）、行政手続法、個人情報保護法 |
| 非対称 | 要件を満たす人を却下すると不服申立て。過誤支給は返還請求 |
| 非構造の入口 | 申請書の自由記入欄、添付書類の写真 |
| 覆せる主体の候補 | 要綱の支給要件 |

## 一覧に無い業界を当てはめる

次の4つを埋められれば、依頼書1に渡せる。

1. **その業界で「やってはいけない」が書かれた文書は何か。**
   法令・ガイドライン・業界団体の自主基準・社内規程。
   **数値や列挙で書かれているものを優先する**
2. **その業界の事故は何か。** 行政処分の公表、事故報告、判例、報道。
   「見逃すと重大／空振りは軽い」の形になっているか
3. **自由文・音声・写真で入ってくるものは何か。** それが無いなら、
   エージェントの仕事が無い
4. **AIがこう言っても、これが優先される、と言えるものは何か。**
   1 がそのまま候補になることが多い

**4 が埋まらないなら、その業界・業務は図にしても山場が作れない。**
別の業務を探したほうが早い。

## 業界をまたいで使える型

上の10件を並べると、**明文ルールの形は3つしかない**ことがわかる。
どれに当たるかで、図での見せ方も決まる。

| ルールの形 | 例 | 図での見せ方 |
|---|---|---|
| **数値の閾値** | 拘束時間の上限、床面積、報告期限の日数 | 値を2つ並べる（AIの判断 / 閾値の結論）。ClaimIntake と同じ形 |
| **列挙** | 派遣禁止業務、重要事項の各号、支給要件 | チェックリスト。「満たしたもの／欠けたもの」を出す |
| **定義** | いじめの重大事態、重大製品事故 | 該当／非該当の判定と、該当した根拠の条文を出す |

いずれも共通するのは、**AIの出力を消さずに、別の値として並べる**こと。
上書きの演出を作らないのは、どの業界でも同じ
（[`agent-flow-diagram-patterns.md`](./agent-flow-diagram-patterns.md) §5）。
